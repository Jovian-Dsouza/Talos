Physics on the phone. Verification on the network. Value in the dataset.

TALOS

06

The flow in five steps. The phone gets a seeded task from a miner pool and runs the physics locally. The pool hands the recording to validators. Each validator replays it in native MuJoCo, the same 3.17 build the browser uses, checks success on its own replay and scores it. Scores become weights on chain every tempo, with a Merkle root of accepted runs. Accepted runs export as a standard robot-learning dataset.
