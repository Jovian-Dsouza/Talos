02 · The solution

Axis-style robot teleop data, verified by Bittensor.

Zero hardware

A phone or laptop is the controller. Physics runs in the browser with MuJoCo WASM.

Trustless checks

Independent validators replay every run in native MuJoCo and agree on chain.

Real-arm ready

Same action space as LeRobot SO-101 datasets. Verified runs play on a real arm.

TALOS

04

Talos is the same idea as Axis, built on Bittensor. Three things: no hardware, just a phone; every run replayed by independent validators instead of a company server; and the data uses the exact SO-101 action space LeRobot uses, so a verified run plays back on a real arm.
