03 · Why Bittensor

Talos runs its own Bittensor subnet

Live on testnet as netuid [__]. Four roles, one incentive: verified, useful data.

RoleWhat it doesWhat it earns
TeleoperatorDrives the robot on a phone or laptopPaid by its pool, in alpha or fiat
Miner (a pool)Recruits people, issues seeded tasks, serves runs to validatorsEmissions in proportion to verified value
ValidatorPulls, replays, scores and dedups runs; sets weights each tempoValidator emissions and dividends
Owner (Talos)Task registry, buyer bounties, dataset packaging and salesOwner emissions plus external revenue

Why pools: a subnet has 256 UID slots, so one person per UID cannot scale. Talos runs an open pool for retail users.

07

Yes, we created our own subnet; it is live on testnet. Miners are pools: each pool is one UID that recruits and pays humans, because a subnet only has 256 slots. Validators replay and score every run and set weights. We, the owner, run the task registry and sell the dataset. Registration and validator details are in the appendix if asked.
