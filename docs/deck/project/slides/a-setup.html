A3 · Subnet

How the subnet is created

01

RegisterSubnet locks TAO and creates the netuid (1 testnet TAO; about 440 TAO on mainnet)

02

start_call turns on staking and emissions

03

burned_register for the validator, the open pool and a second pool

04

add_stake on the validator hotkey to earn a validator permit

05

Docker compose on a VM runs the pools and the validator

Facts

Tempo is 360 blocks, about 72 minutes: emissions land once per epoch.

Bittensor SDK 11 removed Axon and Dendrite, so Talos uses FastAPI with bt.http_auth signed requests.

Development runs on a Docker localnet with fast blocks; the demo runs on testnet.

A3

We own the subnet. One script registers it, starts it, registers the validator and two pools, and stakes the validator. Testnet cost is about 1 TAO; mainnet needs roughly 440 TAO locked, which is why revenue has to come before mainnet. The newest Bittensor SDK dropped Axon and Dendrite, so the network layer is plain signed HTTP.
