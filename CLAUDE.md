# CLAUDE.md

## Commits

- Make a meaningful commit after every major code change. One logical change per commit.
- Use the format `<type>: <description>` (feat, fix, refactor, docs, chore, perf).
- Never add a co-author line or any Claude attribution to commits. No `Co-Authored-By`, no "Generated with Claude Code".

## Style

- Do not use double dashes or double hyphens, and do not use em dashes, in commit messages, comments, docs, or prose. Use a comma, colon, period, or single hyphen instead.

## Approach

- Think from first principles. Work out what the problem actually requires before reaching for existing patterns.
- Write only the main code. Do not write QA tests, unit tests, or any other test code, and do not follow a TDD workflow in this repo.

## Rules

- Please use less amount of TAO for testing. Always use small amounts when doing test transactions.
