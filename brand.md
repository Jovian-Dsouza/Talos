## Interactive robot and practice

The landing arm joint presets are adapted from the user's awign-hackathon-2026 frontend. Only the SO-101 arm is shown, without a wheeled chassis, decks, or electronics. The arm render manifest is derived from that project's SO-101 calibration description and uses the existing decimated robot meshes. The explorer uses the installed Three.js library, loads automatically on the landing page, and renders only when the view changes. The muted background film remains behind the transparent arm canvas; there are no media selection tabs or demo launch buttons. It is a visual preview, separate from the MuJoCo task simulator.

Guest practice on /play uses six bundled rack-vial scenes generated by common.scene.make_scene and common.mjcf.scene_xml. It runs the same browser physics and task checker without ticket requests, uploads, leaderboard updates, or rewards. Authenticated earning runs keep the existing backend verification flow.
